# 店铺效期管家 V2.1

手机浏览器使用的静态网页项目，采用原生 HTML / CSS / JavaScript，适合部署到 GitHub Pages。

## 文件结构

- `index.html`：网页入口、页面结构，以及 CSS / JavaScript 文件引用。
- `style.css`：颜色、卡片、按钮、布局和手机屏幕适配。
- `app.js`：商品资料、批次管理、效期计算、持续提醒、连续换标、历史记录、数据备份与恢复。
- `docs/`：需求说明、数据结构、更新记录、测试清单和代码索引。

## GitHub Pages 部署

1. 解压项目 ZIP。
2. 打开解压后的 `店铺效期管家_V2_项目` 文件夹。
3. 将文件夹里面的内容上传到 GitHub 仓库根目录，不要把外层文件夹整个套在仓库根目录里。
4. 确认仓库根目录直接看得到 `index.html`、`css` 文件夹和 `js` 文件夹。
5. GitHub 仓库进入 Settings → Pages，选择部署分支及 `/ (root)` 目录并保存。

HTML 中的资源引用必须保持：

```html
<link rel="stylesheet" href="style.css">
<script src="app.js" defer></script>
```

不要将它们改成 `style.css` 或 `app.js`，除非同时移动了文件位置。

## V2.1 功能

1. 每个商品可单独设置提前提醒天数（0—365天）。新商品默认10天；旧商品没有该字段时按3天处理。
2. 达到提醒天数后持续出现在首页提醒区；剩余3天内显示重点提醒；到期和过期状态优先显示。
3. 售罄批次不再提醒，但历史记录保留。
4. 快速上货、批次管理、商品资料提供分类快捷入口。
5. 支持连续换标记录，保留原始日期和每次换标日期。
6. 支持 JSON 数据备份与恢复。

## 数据与安全

数据保存在当前网址对应浏览器的 `localStorage`。更换域名、浏览器或设备前，请先导出 JSON 备份。GitHub Pages 只托管网页文件，不会自动同步不同设备的数据。

换标功能仅用于记录日期，不代表可以突破商品实际食品安全期限或相关规定。请以商品实际标签、储存条件及适用规定为准。
