# 店铺效期管家 V2.1

手机浏览器使用的静态网页项目，原生 HTML/CSS/JavaScript。

## 目录
- `index.html`：页面结构与资源入口
- `css/style.css`：页面样式、手机适配、分类快捷入口
- `js/app.js`：商品、批次、效期、连续换标、提醒与数据保存逻辑
- `docs/`：需求与测试说明

## 本次新增
1. 每个商品可单独设置提前提醒天数（0—365天）。新增商品默认10天；旧数据没有该字段时沿用3天，避免旧商品突然大量出现提醒。
2. 达到提醒天数后持续出现在首页提醒区；剩余3天内显示重点提醒；到期和过期状态优先显示。售罄/剩余数量为0的批次不再提醒。
3. 快速上货、批次管理、商品资料增加分类快捷入口，点击分类即可筛选，不必在一个长列表中滑动寻找。

## 部署
将整个项目文件夹内容上传到静态网站托管服务，确保 `index.html` 位于网站根目录。不要只上传 HTML。

## 数据
数据保存在当前网址对应浏览器的 `localStorage`。更换域名/浏览器前请先导出 JSON 备份。

## 注意
提前提醒是网页内提醒：打开网址时显示。网页关闭后是否能推送通知，需要后续接入浏览器通知/推送服务。换标功能仅记录日期，不代表可以突破商品实际食品安全期限或相关法规。
